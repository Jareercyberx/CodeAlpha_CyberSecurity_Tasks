Developer: Syed Jareer Ahmad Shah Jaffri (Cyber Jerry)

This repository contains my submissions for the CodeAlpha internship tasks.

## Tasks Included

1. Task 01: Basic Network Sniffer
A python script to capture and inspect live network traffic.

2. Task 02: Phishing Awareness Training
A presentation covering email header analysis, fake domains, and social engineering defense.

3. Task 04: Network Intrusion Detection System
A real-time network IDS to detect port scanning, flood attacks, and web injection payloads.

## Requirements

Install Scapy before running the scripts:
pip install scapy

Note: Run scripts with Administrator privileges on Windows or using sudo on Linux.
